# Retail Sales Performance and Customer Purchasing Behaviour

### Microsoft Excel | Data Analytics | Business Intelligence

## Project Overview
This project investigates retail sales performance using transaction-level data covering 2022–2025. The analysis focuses on identifying revenue trends, customer purchasing patterns, product category performance and differences between online and in-store sales.

## Objectives
- Evaluate sales performance across product categories.
- Identify monthly and yearly revenue trends.
- Compare online and in-store transactions.
- Explore customer purchasing behaviour.
- Assess relationships between discounts and transaction values.
- Develop practical, data-driven business recommendations.

## Tools and Techniques
- Microsoft Excel
- Data cleaning and validation
- Excel formulas and functions
- PivotTables and PivotCharts
- Data visualisation and KPI reporting

## Dataset
**Source:** Retail Store Sales: Dirty for Data Cleaning

**Platform:** Kaggle

**Dataset link:** https://www.kaggle.com/datasets/ahmedmohamed2003/retail-store-sales-dirty-for-data-cleaning

- Key findings and business recommendations
